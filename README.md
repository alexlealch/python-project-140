## Description
A collection of five interactive CLI (Command Line Interface) brain games. Test your math skills with parity checks, calculators, progressions, GCD, and prime number challenges!

## Requirements
* Python 3.10+
* `uv` (modern Python package manager)

## Installation
To install the games globally on your system, run:

```bash
make install
```

## Usage
To run the games, use the following command:

```bash
make brain-games
```

## Games
Once installed, you can launch any game directly from your terminal:

1. **Even or Odd**: Determine if a number is even or odd.
2. **Calculator**: Solve simple arithmetic expressions.
3. **GCD**: Find the greatest common divisor of two numbers.
4. **Progression**: Guess the missing number in an arithmetic progression.
5. **Prime**: Determine if a number is prime.
